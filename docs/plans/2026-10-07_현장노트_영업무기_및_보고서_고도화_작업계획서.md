## 1. 추진 배경 및 목표

### 1.1 현재 상황
- Next.js 16 + Supabase 기반 10개 핵심 화면 구축 완료
- Vercel 서울 리전(`icn1`) 배포 완료 (`https://groundlog-tau.vercel.app`)
- 초고속 응답 속도 및 멀티테넌시 RLS 데이터 격리 검증 완료

### 1.2 핵심 문제의식 (Why?)
- 제품은 완성되었으나, 실제 업체 대표님이나 현장 소장님을 만났을 때 **"이메일 입력하고 비밀번호 쳐서 로그인해 보세요"**라고 하면 즉각적인 시연이 어렵고 이탈률이 높음.
- 청소·시설관리 업체 대표님이 월 구독료(29,000원)를 결제할 가장 큰 동기는 **"건물주/원청 입주자 대표에게 작업 완료를 완벽하게 증빙하여 재계약을 따내는 것"**임.
- 스마트폰 브라우저에서 사용할 때 정식 앱처럼 느껴지는 **PWA 홈 화면 앱 아이콘**이 필요함.

### 1.3 추진 목표
1. **허들 없는 시연**: 로그인 화면에서 터치 1번으로 관리자/직원 모드를 즉시 둘러볼 수 있는 **데모 원클릭 로그인** 제공
2. **결제 명분 제공 (킬러 기능)**: 건물주 제출용 **A4 일일 작업 보고서 (인쇄 / PDF 저장 / 모바일 링크 공유)** 기능 구현
3. **네이티브 앱 경험**: 스마트폰 홈 화면 추가 시 정식 앱 로고로 실행되는 **PWA Manifest & 앱 아이콘** 셋팅
4. **실전 영업 자료 완비**: 실제 업체 방문 시 들고 갈 **1장짜리 영업 제안서(One-pager)** 및 3분 피칭 스크립트 작성

## 2. 세부 개발 및 문서화 작업 명세 (Task Breakdown)

### 📌 TASK 1. 데모 원클릭 로그인 & 모바일 PWA 셋팅 (시연 편의성 극대화)

#### 1.1 로그인 화면 데모 버튼 추가 (`app/login/page.tsx`, `components/login/DemoLoginButtons.tsx`)
- 로그인 폼 하단에 눈에 띄는 2개의 데모 계정 원클릭 체험 버튼 배치:
  - `[👔 관리자 모드로 바로 체험]` ➡️ `admin@groundlog.com` 자동 로그인 후 `/dashboard` 이동
  - `[👷 현장직원 모드로 바로 체험]` ➡️ `worker@groundlog.com` 자동 로그인 후 `/my-tasks` 이동
- 대표님 스마트폰이나 태블릿에서 URL만 열고 버튼 하나 누르면 즉시 시연 가능하도록 구현.

#### 1.2 PWA 웹앱 매니페스트 및 홈 화면 아이콘 구축
- `app/manifest.ts` (또는 `public/manifest.json`):
  - 앱 이름: `현장노트 (Field Note)`
  - 시작 URL: `/my-tasks` (직원 출근 즉시 실행)
  - 디스플레이 모드: `standalone` (브라우저 주소창 숨김, 네이티브 앱처럼 동작)
  - 테마 색상: `#2563EB` (신뢰감을 주는 블루)
- `public/icons/`:
  - 192x192, 512x512 고화질 앱 아이콘 생성 및 등록
  - Apple Touch Icon(`apple-touch-icon.png`) 메타 태그 연동 (`app/layout.tsx`)

### 📌 TASK 2. 건물주/원청 제출용 일일 작업 보고서 (결제 전환 킬러 기능)

#### 2.1 일일 작업 보고서 전용 뷰어 구현 (`app/reports/[siteId]/[date]/page.tsx`)
- 관리자가 특정 현장의 특정 일자 작업 결과를 한눈에 확인할 수 있는 공식 보고서 페이지:
  - **문서 헤더**: 회사명, 현장명(예: 강남빌딩), 보고 일자, 담당 소장/관리자명, 최종 완료 시간
  - **작업 요약 지표**: 전체 작업 수, 완료율(100%), 점검 체크리스트 달성 수, 등록 사진 수
  - **세부 점검 표**: 작업 항목별 담당자, 체크리스트 상세 내역, 작업 시간
  - **특이사항/이슈 보고**: 시설 파손, 비품 부족 등 현장 전달 사항 강조 박스
  - **현장 증빙 사진 섹션**: 시간대별 Before/After 및 청소/점검 완료 사진 고화질 그리드

#### 2.2 인쇄(Print) 및 공유(Share) 기능 구현
- **A4 규격 인쇄 최적화 (`@media print`)**:
  - 인쇄 시 상하단 불필요한 네비게이션, 버튼 숨김 처리
  - A4 1~2장에 군더더기 없이 깔끔하게 출력되도록 폰트 및 여백 튜닝
  - 브라우저 기본 `window.print()` 연동으로 원클릭 **[PDF로 저장]** 지원
- **카카오톡/문자 공유 기능**:
  - `[📋 건물주 전송용 링크 복사]` 버튼 제공
  - 관리자가 링크를 복사하여 건물주나 카톡 단체방에 바로 전송할 수 있는 깔끔한 UI

#### 2.3 대시보드 및 결과 화면 연동
- [`/dashboard`](file:///h:/lee/groundlog/app/dashboard/page.tsx) 및 [`/tasks/results`](file:///h:/lee/groundlog/app/tasks/results/page.tsx) 화면에 `[📄 오늘 보고서 인쇄/공유]` 바로가기 버튼 추가.
