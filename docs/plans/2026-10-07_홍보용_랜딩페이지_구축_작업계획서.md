## 1. 추진 배경 및 필요성 (Why?)

### 1.1 현재 상황의 한계점
- 현재 도메인(`https://groundlog-tau.vercel.app`)에 접속하면 비로그인 방문자는 무조건 로그인 화면(`/login`)으로 튕깁니다.
- 카카오톡이나 문자, 명함으로 링크를 전달받은 대표님이 사이트에 들어왔을 때, **"이게 도대체 무슨 서비스인지, 무슨 혜택이 있는지"** 알 수 없어 3초 만에 이탈하게 됩니다.

### 1.2 랜딩페이지 구축의 기대 효과
1. **첫인상 신뢰도 극대화**: "신생 개인 앱"이 아니라 "전문 B2B 현장관리 솔루션"이라는 정식 서비스 이미지를 심어줍니다.
2. **잠재 고객 설득**: 대표님들의 고질적인 고통(단톡방 사진 혼란, 건물주의 클레임)을 짚어주고, 3가지 핵심 솔루션을 시각적으로 보여줍니다.
3. **즉각적인 체험 및 전환**:
   - `[무료 데모 둘러보기]` 클릭 시 원클릭 데모 환경으로 즉시 연결
   - `[1개월 무료 체험 신청]` 모달 또는 문의 폼을 통해 실제 고객사 리드(연락처) 확보

## 2. 랜딩페이지 섹션 구성 및 상세 기획

랜딩페이지는 루트 경로([`app/page.tsx`](file:///h:/lee/groundlog/app/page.tsx))에 현대적이고 신뢰감 있는 반응형 디자인(Tailwind CSS 4)으로 구축합니다.  
*(단, 이미 로그인된 사용자는 상단에 [대시보드 바로가기] 버튼을 노출하거나 부드럽게 진입할 수 있도록 처리)*

```
┌─────────────────────────────────────────────────────────────┐
│ 1. Header (로고, 주요 기능, 요금제 안내, [로그인] / [무료체험])    │
├─────────────────────────────────────────────────────────────┤
│ 2. Hero Section (강력한 헤드라인, 서브카피, 2대 핵심 CTA 버튼,  │
│    모바일 실무자 화면 & 관리자 대시보드 입체 목업 비주얼)           │
├─────────────────────────────────────────────────────────────┤
│ 3. Social Proof / Problem (대표님들의 3대 고통 체크리스트)    │
│    - 카톡 사진 찾느라 퇴근 지연? 건물주 클레임 증빙 부재?         │
├─────────────────────────────────────────────────────────────┤
│ 4. Solution & Core Features (3대 핵심 솔루션 카드)           │
│    ① 직원은 큰 버튼 터치 & 사진 촬영 (앱 설치 없음)          │
│    ② 관리자는 실시간 대시보드로 현장별 100% 완료 확인          │
│    ③ 건물주에게 당당히 제출하는 A4 공식 일일 보고서 인쇄/공유   │
│    ④ 교대 시 시설 이슈 누락 없는 현장 인수인계                │
├─────────────────────────────────────────────────────────────┤
│ 5. How It Works (3단계 도입 절차: 3분이면 시작)              │
│    현장 등록 ➡️ 직원 링크 공유 ➡️ 스마트폰 촬영 시작         │
├─────────────────────────────────────────────────────────────┤
│ 6. Pricing Section (파격적인 단순 요금제)                    │
│    월 29,000원 (현장 무제한 / 직원 무제한) + 첫 1개월 전액 무료 │
├─────────────────────────────────────────────────────────────┤
│ 7. FAQ (자주 묻는 질문: 어르신 직원도 쓰기 쉬운가요? 등)     │
├─────────────────────────────────────────────────────────────┤
│ 8. Final CTA & Footer (대표님 무료 체험 유치 & 회사 정보)    │
└─────────────────────────────────────────────────────────────┘
```

## 3. 세부 섹션별 상세 명세

### 3.1 Hero Section (첫 화면 임팩트)
- **헤드라인**:  
  **"카톡으로 흩어지는 현장 청소 사진,  
  이제 「현장노트」 하나로 완벽하게 끝납니다."**
- **서브카피**:  
  "현장 직원은 스마트폰으로 버튼만 터치하고,  
  관리자는 실시간 대시보드와 A4 건물주 보고서로 완벽하게 증빙하세요."
- **CTA 버튼 2종**:
  - `[🚀 1분 만에 데모 체험하기]` ➡️ 로그인 화면 데모 체험으로 스크롤/이동
  - `[🎁 1개월 무료 체험 신청]` ➡️ 빠른 신청 모달 또는 상담 연락처 안내
- **비주얼**:  
  모바일 오늘의 작업 화면(체크리스트+사진)과 PC 관리자 대시보드(진행률 바)가 조화롭게 어우러진 깔끔한 UI 프리뷰 카드

### 3.2 Problem Section (고객 고통 공감)
- *"아직도 단톡방에 올라온 사진 수백 장을 일일이 저장하고 계신가요?"*
  - ❌ "어제 지하주차장 청소했나요?" 건물주 질문에 증빙 사진 찾느라 30분 낭비
  - ❌ 단톡방 사진이 며칠 지나면 만료되어 엑스박스로 표시됨
  - ❌ 어르신 직원분들이 복잡한 앱을 쓰기 어려워함

### 3.3 Solution Section (핵심 가치 4가지)
1. **스마트폰 원터치 체크 (No App Install)**: 앱스토어 설치 없이 링크 터치만으로 출근 즉시 작업 확인
2. **실시간 현장 대시보드**: 사무실 PC에서 오늘 모든 현장의 완료율을 1초 만에 확인
3. **건물주 제출용 A4 보고서**: 버튼 1번으로 사진이 포함된 정식 일일 업무 보고서 인쇄 및 카톡 전송
4. **현장 인수인계 및 이슈 공유**: 시설 파손, 비품 부족 등 전달사항을 사진과 함께 기록하고 해결 관리

### 3.4 Pricing Section (투명하고 부담 없는 가격)
- **월 29,000원 단일 플랜**
  - 관리 현장 수 무제한
  - 직원 계정 수 무제한
  - 사진 저장 용량 넉넉한 제공
  - **첫 1개월 100% 무료 체험 (위약금/신용카드 등록 없음)**

### 3.5 Quick Lead Modal (무료 도입 문의 모달)
- 대표님이 회사명/현장명, 성함, 연락처만 남기면 간편하게 등록되는 간단한 도입 신청 모달(또는 전화 상담 바로 연결) 제공.

## 4. 기술적 구현 방안

1. **파일 구조**:
   - `app/page.tsx`: 랜딩페이지 메인 서버/클라이언트 조합
   - `components/landing/LandingHeader.tsx`: 상단 내비게이션
   - `components/landing/HeroSection.tsx`: 헤어로 비주얼 및 CTA
   - `components/landing/FeaturesSection.tsx`: 핵심 기능 소개
   - `components/landing/PricingSection.tsx`: 요금제 및 무료체험 안내
   - `components/landing/FaqSection.tsx`: 소규모 업체 대표님 맞춤 FAQ
   - `components/landing/LandingFooter.tsx`: 푸터 및 저작권
   - `components/landing/FreeTrialModal.tsx`: 1개월 무료 체험 신청 간편 모달

2. **기존 사용자 UX 고려**:
   - 비로그인 사용자: 멋진 랜딩페이지 노출
   - 로그인된 사용자: 헤더에 `[내 대시보드로 이동 ➔]` 버튼을 강조 노출하여 업무에 방해되지 않도록 처리

3. **성능 및 반응형**:
   - 모바일 최적화 (스마트폰으로 카톡 링크를 열었을 때 완벽하게 읽히는 폰트 크기와 간격)
   - 빠른 로딩 속도 유지 (Next.js 16 SSG/Streaming 최적화)
