## 1. 추진 배경 및 필요성

### 1.1 현장 실무의 문제점
1. **과거 작업 확인 불가**:
   - 현재 `/my-tasks` 페이지는 오직 오늘(`todayStr`) 날짜의 작업만 고정되어 표시됨.
   - 현장 소장님이 "어제 옥상 점검 사진 찍었냐"고 확인할 때 직원이 휴대폰으로 즉각 어제 작업 결과를 확인할 방법이 없음.
   - 퇴근 전 깜빡하고 완료 체크를 누르지 못한 작업을 다음 날 아침에 확인하거나 마무리할 수 없음.
2. **복잡한 달력(캘린더) 도입 시 위험성**:
   - 60~70대 어르신 작업자에게 일반적인 캘린더 피커(달력 팝업)를 제공하면 조작이 어렵고, 현재 오늘 작업을 보고 있는지 어제 작업을 보고 있는지 혼란을 겪을 가능성이 매우 높음.

### 1.2 추진 목표 및 핵심 가치
- **직관적인 1클릭 날짜 이동**: 복잡한 달력 대신 **큼직한 `‹ 이전 날` / `다음 날 ›` 화살표**로 어르신도 1초 만에 날짜를 넘겨볼 수 있게 구현.
- **길 잃음 방지 (안전장치)**: 과거 날짜를 조회 중일 때는 상단에 **`[🟢 오늘 작업으로 돌아가기]`** 원클릭 복귀 버튼과 "과거 작업 조회 중" 주황색 안내 뱃지 노출.
- **미래 날짜 잠금**: 아직 오지 않은 내일 이후의 날짜는 진입할 수 없도록 다음 날 버튼 비활성화.

## 3. 세부 개발 명세 (Task Breakdown)

### 📌 TASK 1. 날짜 연산 유틸리티 확장 (`lib/date.ts`)
- **목표**: 한국 표준시 기준으로 하루 전/하루 후 날짜 및 오늘 여부를 계산하는 헬퍼 함수 추가.
- **구현 내용**:
  ```ts
  // 1. 하루 전 날짜 계산 (YYYY-MM-DD)
  export function getPreviousDate(dateStr: string): string
  // 2. 하루 후 날짜 계산 (YYYY-MM-DD)
  export function getNextDate(dateStr: string): string
  // 3. 오늘 날짜 여부 검사
  export function isTodayKorean(dateStr: string): boolean
  // 4. 미래 날짜 여부 검사 (내일 이후인지)
  export function isFutureDate(dateStr: string): boolean
  ```

---

### 📌 TASK 2. 모바일 날짜 네비게이터 컴포넌트 신설 (`components/my-tasks/TaskDateNavigator.tsx`)
- **목표**: 어르신 작업자분들이 한 손으로도 쉽게 누를 수 있는 큼직하고 명확한 날짜 바 UI 구현.
- **UI 구성**:
  1. **좌/우 이동 버튼**:
     - `‹ 이전 날` (항상 클릭 가능, 큰 터치 영역 `h-11 w-11`)
     - `다음 날 ›` (오늘 날짜일 경우 비활성화 및 회색 처리)
  2. **중앙 날짜 텍스트**:
     - `2026년 10월 10일 (토)`
     - 오늘인 경우: `🟢 오늘` 뱃지
     - 과거인 경우: `🗓️ D-1 (어제)` 또는 `과거 내역` 주황색 뱃지
  3. **오늘 복귀 버튼**:
     - 과거 날짜를 보고 있을 때만 중앙 하단에 **`[ ↩️ 오늘 작업으로 돌아가기 ]`** 눈에 띄는 파란색/초록색 버튼 표시.

---

### 📌 TASK 3. 오늘의 작업 페이지 연동 (`app/my-tasks/page.tsx`)
- **목표**: URL 쿼리 파라미터(`?date=YYYY-MM-DD`)를 지원하고 날짜에 맞는 작업 로그 조회.
- **주요 수정 로직**:
  1. `PageProps`:
     ```tsx
     interface PageProps {
       searchParams: Promise<{ date?: string }>;
     }
     ```
  2. **기준 날짜 판별**:
     - `targetDate = date && !isFutureDate(date) ? date : todayStr`
  3. **자동 생성(Lazy Upsert) 조건부 실행**:
     - **오늘 날짜일 때만** `supabase.rpc("generate_daily_task_logs")` 실행 (과거 날짜 조회 시 불필요한 오늘 템플릿 생성 방지).
  4. **쿼리 대상 일자 변경**:
     - `.eq("work_date", targetDate)`
  5. **과거 작업 카드 텍스트 최적화**:
     - 과거 날짜 조회 시 상단 문구를 `"오늘의 할 일"` ➔ `"{M}월 {D}일 작업 내역"`으로 자연스럽게 전환.

---

### 📌 TASK 4. 작업 상세 페이지 뒤로가기 경로 보존 (`app/my-tasks/[id]/page.tsx`)
- **목표**: 어제 작업 상세를 확인하고 목록으로 돌아올 때 다시 어제 날짜 목록으로 안전하게 복귀.
- **수정 내용**:
  - 상세 페이지 상단 뒤로가기 링크를 `/my-tasks?date=${log.work_date}`로 연결하여 날짜 컨텍스트 유지.
