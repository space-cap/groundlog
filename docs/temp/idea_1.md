# 1인 창업 프로젝트

## 서비스 가칭: **현장노트**

> 미화·시설·경비 업체를 위한
> **현장 작업관리 + 사진기록 + 인수인계 + AI 보고서**

### 핵심 문장

**“직원이 현장에서 체크하고 사진만 찍으면, 관리자는 오늘 작업 내용을 한눈에 확인합니다.”**

---

# 1. 첫 고객을 이렇게 잡습니다

처음부터 대기업을 노리지 않습니다.

### 타깃

* 빌딩 관리업체
* 미화업체
* 시설관리업체
* 경비업체
* 소규모 호텔
* 병원 시설관리업체
* 상가 관리업체

특히 **직원 5~50명 정도인 업체**를 목표로 합니다.

이런 업체는 대형 ERP가 필요하지 않고,

> "직원들이 오늘 일을 제대로 했는지 확인하기 어렵다."

라는 문제가 있습니다.

# 4. 직원 화면

핵심은 **엄청 단순하게** 만드는 겁니다.

```text
오늘의 작업

☐ 1층 로비 청소
☐ 화장실 청소
☐ 계단 청소
☐ 주차장 확인

[사진 촬영]

특이사항
____________________

       [작업 완료]
```

직원이 스마트폰으로 사용하는 서비스이므로

**버튼 크게 / 글자 크게 / 입력 최소화**

가 중요합니다.

---

# 5. 사진 기능

예를 들어 직원이 사진을 3장 올립니다.

```text
📷 1층 로비
📷 화장실
📷 주차장
```

관리자는 PC에서

```text
2026-10-06

김○○

09:12  로비       완료
09:35  화장실     완료
10:05  주차장     완료

사진 3장

특이사항
"화장실 세면대 누수 확인"
```

을 볼 수 있습니다.

---

# 6. 차별화 기능은 이것

## "인수인계"

이게 생각보다 중요합니다.

야간근무자가

```text
특이사항

B3 배수펌프 이상
3층 화장실 전등 고장
지하주차장 누수
```

를 남깁니다.

다음 근무자가 로그인하면

```text
🔴 미처리 인수인계

B3 배수펌프 이상
담당자: 김○○
등록: 21:43

[처리완료]
```

가 보입니다.

이 기능 하나만으로도 **단순 작업체크 앱과 차별화**할 수 있습니다.

# 7. AI는 나중에 붙입니다.

25건

```text

특이사항으로는 3층 화장실 전등 고장,
B3 배수펌프 이상 등이 확인되었습니다.

미처리 항목은 2건입니다.
```

**[PDF 다운로드]**

이렇게 합니다.

# 15. 중요한 건 월 300만원 목표입니다.

# 16. 바이브코딩은 이렇게 시작하세요.

Antigravity/Kilo/Codex 등에 처음부터

> "현장관리 SaaS 만들어줘."

라고 하면 안 됩니다.

범위를 작게 쪼개야 합니다.

첫 프롬프트는 이렇게 시작하는 것을 추천합니다.

```text
나는 "현장노트"라는 소규모 시설관리/미화/경비 업체용
웹 SaaS를 만들고 있다.

목적:
현장 직원이 스마트폰으로 오늘의 작업을 확인하고,
작업 완료 여부와 사진, 특이사항을 기록하면
관리자가 PC에서 작업 현황을 확인할 수 있도록 한다.

이번 단계에서는 AI, 결제, 알림 기능을 만들지 않는다.

먼저 MVP의 기본 구조만 만든다.

기술:
- Next.js
- TypeScript
- PostgreSQL
- Tailwind CSS

필요한 기능:
1. 로그인
2. 회사
3. 현장
4. 직원
5. 작업
6. 작업 완료
7. 사진
8. 특이사항
9. 관리자 대시보드

사용자 역할:
- ADMIN
- MANAGER
- WORKER

중요:
- 모바일 우선 UI
- 직원 화면은 최대한 단순하게
- 관리자 화면은 PC 사용을 기준
- 처음부터 과도한 추상화나 복잡한 아키텍처를 만들지 않는다.
- 실제 실행 가능한 코드를 작성한다.
- 기능을 한 번에 모두 구현하지 말고 단계별로 구현한다.

먼저 프로젝트 구조와 DB 설계만 제안하고,
내 승인을 기다려라.
```

**이 프롬프트부터 시작하는 것을 권합니다.**

# 17. 그리고 사업적으로 가장 중요한 원칙

처음부터

**"내가 300만원 벌 수 있는 서비스를 만들어야지."**

라고 생각하면 안 됩니다.

첫 번째 목표는 딱 하나입니다.

> **"돈을 낼 사람이 실제로 존재하는가?"**

입니다.

그래서 순서는

```text
아이디어
 ↓
MVP
 ↓
실제 업체 1곳
 ↓
무료 사용
 ↓
불편한 점 발견
 ↓
수정
 ↓
월 29,000원 결제
 ↓
3개 업체
 ↓
10개 업체
 ↓
30개 업체
 ↓
50개 업체
```

입니다.

**50개 업체까지 갈 수 있으면 그때부터 제대로 된 1인 SaaS 사업입니다.**

그리고 저는 이 프로젝트에서는 **개발보다 영업을 더 중요하게 봅니다.**
제품을 3개월 만드는 것보다 **2주 만에 만든 뒤 업체 3곳에 실제로 써보게 하는 것**이 훨씬 중요합니다.

원하시면 다음 단계에서 바로 **「현장노트」의 실제 화면 10개를 제가 설계해서, Antigravity/Codex에 그대로 붙여넣을 수 있는 바이브코딩 프롬프트 세트**로 만들어드리겠습니다.
